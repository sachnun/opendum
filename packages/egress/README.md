# @opendum/egress

Outbound request safety and proxying.

## API

- `ssrf` - SSRF checks for user-supplied URLs.
- `guard` - egress guard.
- `unroxy` - unroxy egress integration.

## Commands

| Command | Description |
| --- | --- |
| `pnpm test` | Unit tests |
| `pnpm typecheck` | `tsc --noEmit` |
