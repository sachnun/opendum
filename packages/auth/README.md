# @opendum/auth

Better-Auth configuration and the database-backed custom store.

## API

- `service` - server auth service and session helpers.
- `custom-store` - provider/account access store.
- `types` - auth result and validation types.

## Commands

| Command | Description |
| --- | --- |
| `pnpm test` | Unit tests |
| `pnpm typecheck` | `tsc --noEmit` |
