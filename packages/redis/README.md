# @opendum/redis

Redis client plus key and session-affinity helpers.

## API

- `client` - shared Redis client factory.
- `keys` - key builders.
- `session-affinity` - sticky-account routing helpers.

## Commands

| Command | Description |
| --- | --- |
| `pnpm test` | Unit tests |
| `pnpm typecheck` | `tsc --noEmit` |
